## Problem Statement

Managing student information manually can become difficult when multiple student records are involved. A simple computer-based system is needed to store basic student information and provide easy operations for
viewing, adding, updating, and deleting records. The Student Record Management System provides a simple Python-based solution using a menu-driven command-line interface.


## Scope of the Project

The current project focuses on basic student record management.

The system can:

-   Store student information temporarily in a Python dictionary.
-   View a record using Student ID.
-   Add new student records.
-   Display all student records.
-   Validate selected user inputs.


## Target Users

The project is intended for:

-   Students learning Python programming.
-   Teachers or evaluators demonstrating basic programming concepts.
-   Users who need a simple example of student record management.

## High-Level Features

1.  Student ID based record viewing
2.  Add new student
3.  Display all students
4.  Input validation
5.  Menu-driven command-line interface
