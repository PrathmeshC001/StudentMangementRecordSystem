# Student Record Management System

## Project Overview

The Student Record Management System is a beginner-level Python project for storing and managing basic student information. The program provides a simple command-line interface where a user can view a student record using a Student ID, add a new student, display all students, update a record, and delete a record. This project was developed to practice basic Python concepts such as dictionaries, functions, loops, conditional statements, input, type conversion, and dictionary operations.

## Features

 View a student record using Student ID
 Add a new student
 Display all student records
 Validate Hosteler/Day Scholar status
 Menu-driven command-line interface
 Exit the program safely

## Technologies / Tools Used

 Python 3
 GitHub
 Command Prompt / Terminal or any Python IDE

## How to Install and Run

1.  Install Python 3 on your computer.
2.  Download or clone this repository.
3.  Open the project folder in a terminal.
4.  Run: python Collegeproject.py

## How to Use

When the program starts, the user can:

 Enter a Student ID to directly view that record.
 Type `NEW` to add a new student.
 Type `MENU` to open the main menu.
 Type `EXIT` to close the program.

 The Student ID starts with VIT and then number like 001,002,003,004,005.

 So for searching a student record just enter VIT001, it will show you his record.


### Main Menu

1. Search Student
2. Add New Student
3. Display All Students
4. Back
